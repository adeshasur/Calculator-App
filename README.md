# Premium Calculator

A sophisticated, high-performance calculator application built with a minimalist monochrome aesthetic. This project prioritizes visual excellence, tactile responsiveness, and mathematical accuracy.

![Calculator Screenshot](Screenshot%20(1080).png)

## ✨ Features

- **Minimalist Design**: A premium "Deep Black" monochrome theme for maximum focus and readability.
- **Glassmorphism**: Subtle glass-like interface elements for a modern, high-end feel.
- **Responsive Layout**: Built with **CSS Grid** for pixel-perfect button alignment across devices.
- **Physical Keyboard Support**: Use your numbap or operator keys for a seamless desktop experience.
- **Tactile Feedback**: Interactive "press" animations for both mouse and keyboard inputs.
- **Accurate Arithmetic**: Robust logic that handles thousands-format parsing and floating-point precision (e.g., `0.1 + 0.2 = 0.3`).

## 🛠️ Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Vanilla CSS with modern grid layouts and glassmorphism effects.
- **JavaScript**: Custom logic for arithmetic, formatting, and event handling.

## ⌨️ Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `0-9` | Input Numbers |
| `.` | Decimal Point |
| `+`, `-`, `*`, `/` | Operators |
| `Enter` or `=` | Calculate Result |
| `Backspace` | Delete Last Digit |
| `Escape` or `C` | Clear All |
